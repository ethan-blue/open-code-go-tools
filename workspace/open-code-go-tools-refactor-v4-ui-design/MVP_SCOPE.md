# MVP_SCOPE

## 必须交付 (In-Scope)：
1. **API 连接测试**: 点击 ApiSection.tsx 中的「测试连接」，调用后端进行 API Key 可达性测试，并渲染 Loading 与 Success/Fail 状态。
2. **复制与脱敏**: 允许用户一键复制 API 代理配置的 Token；API Key 在前端显示时进行脱敏处理。
3. **安全配置持久化**: 将「启用验证」与「请求限流」绑定到前端 state，且在 Save 时落盘到 `config.json` 的安全字段中。
4. **备份拖拽交互**: 支持拖拽备份 JSON 文件完成瞬间导入，且提供下载备份文件的功能（已完成底层骨架，需确保与后端完全对齐）。

## 延迟交付 (Out-of-Scope)：
- 自动更新主程序二进制。
- 复杂的统计图表展示。
- 多账号同步。
