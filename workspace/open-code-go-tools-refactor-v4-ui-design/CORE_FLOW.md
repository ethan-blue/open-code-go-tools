# CORE_FLOW

为了让真实用户能把 OCGT 跑起来，必须打通以下最简闭环流程：

```
[启动客户端] -> [检测/加载本地 JSON 配置] -> [显示主控制台/健康度]
      |
      v
[进入设置 Settings] -> [配置 API 代理与 Providers (Gemini/Claude Key)] 
      |
      v
[点击 "测试连接" (验证 Key 有效性)] -> [保存配置 (触发后端代理热重载)]
      |
      v
[启动代理服务] -> [下游 IDE (如 Claude Code) 请求 127.0.0.1:8317]
      |
      v
[成功透传 / 限流控制生效]
```

## 关键断点（目前 MVP 阻碍点）：
1. **热更新保存**: 在前端修改「安全设置」和「API 代理」后，保存必须生效，且后端需要触发热重载以应用新的限流或认证。
2. **状态感知**: 用户配置完 Provider 后，必须能一键看到该 Provider 的可用性（“测试连接”功能）。
